<objective>
Prove the D-15 write-back path end to end, in a real browser, against a real `@powersync/web`
database: a programmed session whose cycle carries a `routine_exercise_cycle_target` override must
write that override row when the user taps "Also update my program", and must leave the base
`routine_exercise` row alone.

This is the end-to-end verification half of 05-11's tracer. 05-11 wires the slice and proves it at
unit level plus a live schema push; this plan raises the same invariant to browser-real evidence,
which is the only kind that would have caught the original gap (the unit tests for
`resolveWriteBackTarget` were green the whole time the production caller fed it a hardcoded null).

Purpose: close VERIFICATION.md's `human_verification` item *"With a program that has at least one
routine_exercise_cycle_target override active … confirm the override (not the base row) reflects the
edit"* with an automated, repeatable run instead of a manual check.
Output: a registered, passing `target-write-back` spec plus the harness seeding it needs.
</objective>
