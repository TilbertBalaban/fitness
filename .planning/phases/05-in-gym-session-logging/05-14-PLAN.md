<objective>
Make all three note levels actually reachable, and put the warm-up badge where the contract says it
lives.

`setNote({ level, id, text })` writes three independent nullable columns and is unit-tested per
level; `NoteSheet` already accepts all three levels via props. Only the exercise-level trigger is
mounted anywhere in the app, so a user following LOG-16's literal promise can attach exactly one of
the three notes today (WINDOWS #118, VERIFICATION gap 2). Both missing surfaces already exist — the
set row and the session Menu — so this is wiring plus sheet plumbing, not new component invention.

The same plan closes the cosmetic warm-up badge gap (WINDOWS #109) because it lands in the same
file: `05-UI-SPEC.md` puts the leading "W" badge ahead of the set-number column *inside* the row,
but it is currently rendered by `ExercisePageView` wrapping the row from outside, so every other
`SetRowView` consumer (the summary's correction rows) renders warm-up rows with no badge at all.

Purpose: LOG-16 stops being blocked, and the row contract becomes true for every consumer.
Output: a long-press note trigger on every set row, a Session Note row in the Menu, the badge
relocated into `SetRowView`, and a browser-real spec proving all three levels write their own column.
</objective>
