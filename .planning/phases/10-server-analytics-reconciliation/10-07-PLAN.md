## Grep-gate hygiene

Every **negative** grep in this plan's acceptance criteria (a count that must be 0) is evaluated over
**comment-stripped** source. Strip first, then count — for TypeScript and TSX use
`grep -vE "^\s*(//|\*|/\*)" <file> | grep -c "<token>"`, and for YAML use
`grep -v "^\s*#" <file> | grep -c "<token>"`.

This matters because several tasks below deliberately ask for a comment that names the very thing a
gate forbids in code. An unstripped count would make the explanation self-invalidating, and the only
way to satisfy it would be to delete the explanation — exactly backwards. Positive greps (a count
that must be at least N) are evaluated over the raw file.
