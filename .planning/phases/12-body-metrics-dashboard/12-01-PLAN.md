<objective>
Make `body_metric` writable end-to-end for the first time: a bodyweight logged on a device reaches
Postgres. This closes the debt `packages/api-contracts/src/sync.ts` has carried since Phase 2, where
a comment names Phase 12 as the owner of both remaining `PUSH_DEFERRED_TABLES` entries.

Purpose: BODY-01 and BODY-02 are the same write with a different `kind` (D-05). Every later plan in
this phase — the overview screen, the trend detail, the quick weigh-in — reads and writes through the
module this plan creates. Nothing downstream is buildable until this path is proven against a real
Postgres.

Output: the closed body-metric vocabulary and its `docs/` reference, the `body_metric` push apply
path on the server, the client write module, and an API e2e spec that proves ownership and
vocabulary enforcement against a live database.
