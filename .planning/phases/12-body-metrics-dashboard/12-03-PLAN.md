<objective>
Give the user progress photos: capture on either target, a bounded downscale, device-local storage,
a synced metadata row, and a gallery that is honest about which photos this device actually holds.

Purpose: this is the phase's only genuinely new architectural problem. `expo-file-system`'s
`File`/`Paths` API has no web equivalent for app-private storage, so the storage module must be
platform-split from the first line — RESEARCH Pitfall 1 is explicit that a web bundle will compile
and then throw at runtime. The honest consequence of D-15 (bytes stay on the device) is a visible
placeholder, and this plan ships it as a deliberate product statement rather than letting it surface
as a broken image.

Output: three `.web.ts`-split photo modules, `progress_photo`'s push apply path, the gallery with its
placeholder, the capture-confirm sheet, and a real-browser Playwright spec proving the
capture-store-read round trip against real IndexedDB.

**Shared-seam ownership.** This plan is the wave-2 owner of `packages/api-contracts/src/sync.ts`,
`apps/api/src/sync/sync.service.ts` and `apps/api/src/sync/patch-update-set.ts` (12-01 owned them in
wave 1, 12-05 owns them in wave 3). It is also the wave-2 owner of the three append-only shared
seams: `apps/mobile/app/__durability.web.tsx`, `apps/mobile/lib/db/test-support.ts` and
`apps/mobile/playwright.config.ts`'s `durability` `testMatch` array. **Append only — never rewrite,
never reorder, never remove an existing entry from any of the three.**

no story is framed here. See 12-01's `<planner_assumptions>`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device -> `POST /v1/sync/push` | Untrusted client-authored `progress_photo` op payloads cross here, including a client-chosen `storage_key`. |
| photo bytes -> device storage | Camera/library bytes enter app-private storage (native document directory, browser IndexedDB); they must never cross the network boundary. |
| PowerSync `user_data` stream -> device | Another device's `progress_photo` metadata row arrives without its bytes — the R27 placeholder is the honest rendering of that boundary. |
