probe produced no category for GYM-05, so no acceptance criterion is derived from it. The planner's
working interpretation, recorded here so a verifier can challenge it rather than inherit it
silently: "without leaving the entry screen" is satisfied by the band living inside the docked
keypad's own reserved slot, so the breakdown updates as digits are pressed and no navigation, modal
or sheet is involved. The band is not required to appear for a set row whose field is not currently

D-20's reserved-slot contract and must be escalated, not resolved inside a plan.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-06-04 | Denial of Service | per-keystroke band computation | medium | mitigate | The inventory is read once per session read, the achievable set is derived once per inventory, and the band state is memoised on the inventory and target pair — the view itself performs no computation and runs no effect. |

</threat_model>
