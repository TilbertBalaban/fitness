<objective>
**As a** lifter who logs Bulgarian split squats left-then-right and finishes bench with a drop set, **I want to**
get one sensible recommendation per exercise anyway, **so that** the advanced set types Phase 7 gave me do
not quietly break the thing Phase 8 exists to do.

This plan finishes D-11's normalisation boundary and adds PRGR-03's failure-set rule. It expands the
tracer's top-set fold outward to the two Phase 7 shapes it deliberately left: per-side pairs, which get the
weaker side (D-12), and failure sets, which progress on reps at the same load rather than on the
midpoint-plus-RIR formula. It also pins, with a test rather than a claim, that supersets require no
handling at all — a plan that wrote superset branching into the engine would be solving a problem that
does not exist at this layer, and the absence needs to be provable so a later reader does not "fix" it.

Purpose: make the engine correct for every set shape Phase 7 can produce, at one boundary, once.
Output: a completed normalisation boundary and the failure-set rule, both wired into
`recommendNextPrescription`.
</objective>
