grouped-set columns cannot be used to attach my sets to someone else's workout and that a grouped set
survives the app being killed, **so that** the features this phase added did not quietly widen the blast
radius of a bug or a bad actor.

instructs the plan to ADD a verification case rather than assume the existing suite covers it by name —
`poison-pill.e2e-spec.ts` predates D-16's session-only superset design entirely. This plan closes both,
proves `sync.service.ts` needs no change by exercising it rather than by reading it, and lands the
durability spec 07-VALIDATION.md makes a phase gate ("at least one clean durability Playwright run
exercising a grouped set end to end").

Output: the phase's security and durability evidence, and a signed-off 07-VALIDATION.md.

session 2. Assert that reading session 1 back yields a group whose live members are all within session 1 —

exercise list, so the containment is client-side by construction and the server check is ownership through
`workout_session` alone.
