<objective>
**As a** lifter doing single-arm dumbbell rows where the left side is genuinely weaker, **I want to** log
the two sides separately under one set, **so that** my history records what each arm actually did instead
of averaging away a real imbalance.

Purpose: per-side is the fourth feature riding D-05's single grouping mechanism, and it deliberately adds
no new layout — it reuses the badge slot, the indent, and the child-row anatomy the earlier plans built.
The two genuine decisions here are (1) the mode is derived from data with no column (D-21), and (2)
toggling it governs only future sets and never rewrites a logged value (D-22, CF-08). The second is why
the mode needs an ephemeral per-exercise override in addition to the derived value: with a purely derived
mode, an exercise that already has a paired set could never be turned back off.

Output: SETS-09 complete, and the phase's last new user-facing behaviour.
</objective>
