<objective>
**As a** lifter finishing a myorep set, **I want to** tap once after each rest-pause mini-set to add the
next one under the same logical set, **so that** the whole cluster is recorded as the one set it was
without me guessing up front how many mini-sets I had in me.

Purpose: 07-01 proved one sub-entry can be created and rendered. This plan makes the group something the
lifter can actually grow and prune, and completes the three grouped features that share the one mechanism
D-05 fixed — drops (SETS-02), myoreps (SETS-03) and partials (SETS-05). Myorep is the one divergence from
drop/partial's parent-stays-normal rule: for a myorep the parent IS the activation set (D-07), so the
add control's visibility rule has to cover a parent as the group's "most recent entry", not only a child.

Output: the "+ Add {type}" control, the per-child remove glyph, and the pure functions that decide when
each appears — SETS-02, SETS-03 and SETS-05 complete.
</objective>

## Trust Boundaries
