<objective>
**As a** lifter, **I want to** have my warm-ups counted as warm-ups and my partial reps kept out of my
personal records, **so that** the numbers the app shows me are honest and the records it asks me to beat
are records I actually set.

Purpose: this phase turns five reserved `set_type` values into written ones. The rule "which set types
count" currently exists as a bare string comparison in five separate places
(`session-query.ts` twice, `history-query.ts`, `summary-query.ts`, `ExerciseStrip.tsx`), and
`personal-records.ts` carries a sixth, subtly different one. Five newly-writable types is exactly the
pressure that makes those copies drift. D-17 and D-18 replace them with two named predicates; 07-01
published them, this plan migrates every call site it owns. `ExerciseStrip.tsx`'s copy — the fifth
location 07-RESEARCH found beyond CONTEXT.md's four — belongs to 07-03.

Output: SETS-06's warm-up exclusion becomes explicit rather than incidental, and D-18's records rule
lands before any `partial` row can be written by 07-05.
</objective>
