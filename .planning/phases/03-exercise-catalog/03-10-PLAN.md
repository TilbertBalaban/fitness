  <action>
**`apps/mobile/lib/catalog/smart-swap.ts` (new).** Export
`scoreAlternatives(target, candidates, mappings, preferences, constraints)` returning
`ScoredCandidate[]`, plus `explainMatch(target, candidate, signals)`, `SWAP_SCORE_THRESHOLD` and
`SWAP_RESULT_CAP`.

A pure function: no database handle, no React import, no module-level mutable state, no
`Date.now()`. It takes plain arrays and returns a new array, and it neither mutates nor reorders
its inputs. That purity is what makes the concurrency property in `<behavior>` true by
construction rather than by luck, and it is why the property is cheap to assert.

**Exclusions first, scoring second.** Drop the target itself, every exercise with a
`user_exercise_preference` row for the current user where `never_suggest` is true or `archived_at`
is non-null, and every candidate the equipment constraint forbids. Reuse the archive predicate
from `catalog-filter.ts` rather than writing a second one — one archive code path for the whole
app is the property PITFALLS.md §11 demands.

**Scoring signals, in the priority CONTEXT.md's own reasoning implies:**
1. **Shared muscle overlap, weighted.** The dominant signal. Sum, over muscle groups present in
   both the target's and the candidate's mappings, the product of their `weight_factor` values,
   with a primary-primary match worth strictly more than a primary-secondary one. Parse the exact
   decimal strings to numbers inside the scorer only; do not change the stored representation.
2. **Matching `movement_pattern`.** A strong secondary signal — a horizontal-push swap for a
   horizontal-push target. A null pattern on either side scores neutral, not negative.
3. **Equipment constraint satisfaction.** Already applied as a filter above; additionally give a
   small bonus for matching the target's own `equipment_required`, so a like-for-like machine
   ranks above a different modality when muscle overlap ties.
4. **`variation_of_id` sibling.** A bonus, never a filter. CONTEXT.md is explicit that siblings
   alone are far too narrow — a lat pulldown is a reasonable pull-up alternative and shares no
   parent — and the test asserting exactly that is what stops the bonus quietly becoming a gate.

**Threshold and cap.** Drop anything below `SWAP_SCORE_THRESHOLD` — a bad suggestion mid-workout
is worse than none, and the empty state exists for that case. Cap the result at
`SWAP_RESULT_CAP` (5), so the detail-screen section never needs a nested scroll region.

**Total order.** Score descending, then name ascending, then id ascending. Reuse
`sortCatalogResults`'s comparator shape from `catalog-filter.ts`; the id tie-break is what makes
the order total so a re-render over identical data cannot reorder suggestions.

**`explainMatch`.** Returns the one-line plain-language `why` string from the signal that
contributed most: shared primary muscle names the muscle ("Same primary muscle: chest"), matching
pattern names the pattern, sibling names the parent movement. It must never return an empty string
and must never surface a numeric score — a score is not an explanation, and `FEATURES.md`'s point
is that the user is told *why*, not *how much*. Keep the strings descriptive of the movement; they
must not evaluate the user or their body.

**Deliberately not:** any embedding, similarity model or learned ranking. `PROJECT.md` rules that
out project-wide, and a black-box similarity score cannot produce the explanation this
requirement's own UI contract mandates.

**The equipment-constraint seam.** Type `SwapConstraints` as
`{ excludeEquipment?: string[]; allowEquipment?: string[] }`. Phase 7 owns gym profiles and
`equipment_profile.machine_availability`; do not build any of it here, but do not shape the
parameter so that it cannot later be fed from that column. An allow-list plus an exclude-list
covers both the "these are the machines this gym has" and the "this one is taken right now" cases
without knowing anything about the profile model.

| derived score -> user-facing recommendation | A computed ranking is presented to a user who will act on it in a gym |
