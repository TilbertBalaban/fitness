## Design System

| Property | Value |
|----------|-------|
| Tool | none — shadcn is not applicable to this codebase. shadcn's component primitives are built on Radix UI, a React-DOM-only library; this project is React Native + React Native Web (Expo Router, NativeWind 4), and Radix cannot run inside a native `View`/`Text` tree. `components.json` correctly does not exist. |
| Component library | Hand-rolled RN components under `apps/mobile/components/` (`PrimaryButton`, `TextField`, `ErrorBanner`, `AuthScreenLayout`, `SignOutDialog`, `PlaceholderScreen`), styled with NativeWind 4 className utilities against the token set below. This phase follows the same rule: Ionicons for static, non-recoloring iconography (list-row chevrons, filter-chip check), plain themed `<Text>` for anything whose color must react to state. |
| Font | System default — no `fontFamily` override exists in `apps/mobile/tailwind.config.js`; the platform default (San Francisco on iOS, Roboto on Android, system-ui stack on web) is the established choice and this phase does not change it. |

## Spacing Scale

Declared values (already shipped in `apps/mobile/tailwind.config.js`, multiples of 4 — inherited unchanged from Phase 1):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- **48×48px minimum hit target** for every icon-only or short-label tappable control (filter chips, list-row tap area, archive/never-suggest toggles, the swap-suggestion "why" disclosure). This is not a new rule — it is the exact convention already shipped in `TextField`'s Show/Hide control and `SignOutDialog`'s buttons (`style={{ minWidth: 48, minHeight: 48 }}`), carried forward because this is the first phase with a dense tap-heavy list surface where it is easy to regress.
- **4:3 fixed-aspect image tile** on exercise-detail and list-row thumbnails is a layout constant, not a spacing-scale value — it exists to guarantee zero layout shift while an image resolves or fails (see UI Considerations, media/empty and media/error rows).

## Typography

Declared values (already shipped in `apps/mobile/tailwind.config.js` `fontSize`/`fontWeight` — inherited unchanged; this phase does not add a fifth size or a third weight):

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 400 (regular) | 20px (1.43) |
| Body | 16px | 400 (regular) — 600 (semibold) is the accepted exception for CTA/button text at body size, matching `PrimaryButton`'s existing `font-semibold` usage | 24px (1.5) |
| Heading | 20px | 600 (semibold) | 24px (1.2) |
| Display | 28px | 600 (semibold) | 34px (1.21) |

**Phase-specific role mapping:**
- Screen titles ("Exercises", exercise detail name) → Heading.
- Section headers within a screen (e.g. "Target Muscles", "Suggested Alternatives") → Body, semibold.
- List-row exercise name → Body, regular, single line, truncated (see UI Considerations).
- List-row muscle/equipment tags, result-count line, filter-chip labels → Label.
- Cue/instruction body text on the detail screen → Body, regular, multi-line, no truncation.
- Empty/error state headings → Heading; empty/error state body copy → Body, regular, `text-foreground-muted`.

## Color

Declared values (already shipped in `apps/mobile/global.css` CSS custom properties, resolved through NativeWind's `dark:` class — inherited unchanged):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` light / `#09090b` dark (`background`) | Screen background behind the exercise list, detail screen, and forms |
| Secondary (30%) | `#f4f4f5` light / `#18181b` dark (`surface`) | List-row backgrounds, filter-chip resting background, text-input backgrounds, image-placeholder tile background, card containers on the detail screen |
| Accent (10%) | `#2563eb` light / `#3b82f6` dark (`accent`) | Reserved for exactly: (1) the primary CTA button fill ("Add Custom Exercise", "Save Exercise"), (2) a selected/active filter chip's border+label color, (3) a focused text-input border (`TextField`'s existing pattern), (4) the selected state of the tab-bar icon (inherited, unchanged by this phase) |
| Destructive | `#dc2626` light / `#ef4444` dark (`destructive`) | Archive-confirmation button fill only; inline validation-error text on custom-exercise form fields (matching `TextField`'s existing `error` prop styling) |

Accent reserved for: primary CTA fill, active-filter-chip indicator, focused-input border, selected-tab icon. Never used for body text emphasis, list-row backgrounds, or as a general "interactive" tint on every tappable element.
