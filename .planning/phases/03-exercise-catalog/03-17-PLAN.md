## The claim being pinned

`app/_layout.tsx:110-113` declares:

```
<Stack.Protected guard={signedIn}>
  <Stack.Screen name="(tabs)" />
  <Stack.Screen name="exercises" />
</Stack.Protected>
```

`<Stack.Screen name="exercises" />` matches a single route named `exercises`. Whether the segment's other
three routes are covered by it depends entirely on expo-router's route-hoisting rule, stated in
`expo-router/build/getRoutes.d.ts`'s own doc comment:

> Routes in directories without `_layout` files are hoisted to the nearest `_layout`. The name of the route
> is relative to the nearest `_layout`.

With `app/exercises/_layout.tsx` present, the four route files become children of one `exercises` layout
node, and the single protected screen covers all four. Without it, they hoist to the root stack as
siblings named `exercises/[id]`, `exercises/new`, `exercises/edit/[id]` — names the protected
`<Stack.Screen name="exercises" />` does not match — while the list route collapses to `exercises` and stays
covered. That asymmetry is precisely the hole 03-14 closed as a byproduct, and it is what this test pins.

## Why a file-existence assertion is not acceptable here

`expect(fs.existsSync('app/exercises/_layout.tsx')).toBe(true)` would pass against a `_layout.tsx` that
exported an unprotected stack, against one that declared only two of the four screens, and against a root
layout that had moved `exercises` out of the guard entirely. This plan asserts the **relationship**: what the
route tree actually resolves to, and where the `exercises` screen actually sits relative to the guard
boundary.

## Why the test proves its own power in-suite

The two prior gap-closure rounds each shipped tests that passed while the user-visible defect survived. This
test therefore runs its assertions **twice**: once against the real on-disk key list, and once against the
identical list with `./exercises/_layout.tsx` removed. The second run asserts the bypass shape appears. A
reader — and a future CI failure — can see from the test file itself that the first assertion would fail
without the segment layout, without anyone having to delete a file to find out.
