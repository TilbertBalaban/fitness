# Build @fitness/* workspace packages on EAS before Metro bundles

## Problem
EAS Android preview build b202f4b2 failed in `expo export:embed`: Metro found
`@fitness/api-contracts/package.json` but its `main` (`./dist/index.js`) did not exist.
All six `packages/*` workspace packages point `main` at `dist/`, which is gitignored and
produced only by `tsc` via turbo. The EAS worker runs `pnpm install` and then bundles;
nothing builds the packages in between.

## Tasks
1. Add an `eas-build-post-install` script to `apps/mobile/package.json` running
   `pnpm --filter="mobile^..." run build`. EAS executes this hook after install, with
   cwd `apps/mobile`; pnpm resolves the workspace root itself. The `^...` selector
   builds every dependency of `mobile` (not `mobile` itself) in topological order.
2. Verify locally: delete `packages/*/dist`, run the filter, confirm all six dist dirs
   are recreated.

## Done when
- The hook exists in `apps/mobile/package.json`.
- The local verification recreates all six `dist/` directories.
